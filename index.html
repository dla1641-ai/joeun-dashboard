수탁처리능력확인서 자동 생성

                                
수탁 원본 PDF는 팀 공유 Drive에서 불러오고, 처리능력 기본 숫자는 팀 공용 처리장 DB에서 불러옵니다. 원본 PDF 페이지는 그대로 보존하고 변경값만 위에 반영합니다.

                            

                            원본 미등록
                        


                        

                            

                                
                                
                                
                                
위의 「처리자 정보 → 처리장 선택」과 자동 연동됩니다. 여기서 다시 선택할 필요가 없습니다.

처리능력 입력값

                                    

                                        팀 공용 DB의 숫자는 기본값으로 자동 입력되며 화면에서도 언제든 수정할 수 있습니다.

                                        현재보관량 + 1일평균반입량 + (금회수탁량 - 1일처리량)으로 자동 계산됩니다.
